# Layout / Section Header

Mono eyebrow (`action-default`), heading at H1 size (h2 by default), Body large lead in `text-secondary` capped at 680px, then an optional action. 32px before the section content.

## React

```tsx
<SectionHeader eyebrow="One system. Different responsibilities." title="Community, consultation and reports, each in its own voice." />
```

```html
<header class="ds-section-header"><p class="ds-eyebrow">…</p><h2 class="ds-type-h1">…</h2><p class="ds-type-body-large ds-secondary ds-reading">…</p></header>
```
