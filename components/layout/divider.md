# Layout / Divider

**NOT IN FIGMA** (repo-owned). 1px `border-subtle`, full width. Use between headed sections of detail pages (report detail, settings) so content stays open instead of boxed (card rule).

## React

```tsx
<section>…</section>
<Divider />
<section>…</section>
```

## Reference markup

```html
<hr class="ds-divider">
```
