# Layout / Section

Section rhythm comes from `data-density` (comfortable 64/80, compact 24/32). `band` gives a full-width `surface` band with thin `border-subtle` edges to separate it from canvas sections; `wash` puts decorative washes behind it.

## React

```tsx
<Section band aria-labelledby="community-h">…</Section>
```

## Reference markup

```html
<section class="ds-band"><div class="ds-container ds-section">…</div></section>
```
