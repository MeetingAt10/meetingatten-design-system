# Layout / Wash

Three radial washes (`wash-accent` top right, `wash-secondary` bottom left, `wash-info` top center) on `canvas`. Light: the 100 / 50 tints; dark: the 950 steps. Text on every wash is contrast-checked in both themes ([treatments](../../foundations/treatments.md)). Decoration only: never the only carrier of meaning.
