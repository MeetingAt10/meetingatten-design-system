# Radius

Source: Figma "ACCS 2026 / Dimensions" and Foundations 03.2. Controlled softness: **0 tables, 4 chips, 6 controls, 8 cards, 12 overlays.** Pills are reserved for compact counts, not every surface.

| Token | Value | Use | Components |
|---|---|---|---|
| `radius/0` | 0 | Tables (cells), select popup | Reports Table cells |
| `radius/4` | 4px | Chips | Badge / Role, Status, Severity; checkbox box |
| `radius/6` | 6px | Controls | Buttons, text field, select option, search, icon button, tab/item/link, consultation slot, inline alert |
| `radius/8` | 8px | Cards | Announcement/Forum Card, Privacy Notice, Toast, Reports Table container, Report Record, View State |
| `radius/12` | 12px | Overlays | Modal |

Tailwind: `rounded-chip` (4), `rounded-control` (6), `rounded-card` (8), `rounded-overlay` (12).
