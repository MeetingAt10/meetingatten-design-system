# Z-index

**NOT IN FIGMA.** Minimal stacking scale.

| Token | Value | Layer |
|---|---|---|
| `z/sticky` | 100 | Top bar, sidebar |
| `z/dropdown` | 200 | Select popup |
| `z/modal` | 400 | Modal and scrim |
| `z/toast` | 500 | Toast |

Tailwind 4 has no z-index theme key: use `z-(--ds-z-modal)`.
