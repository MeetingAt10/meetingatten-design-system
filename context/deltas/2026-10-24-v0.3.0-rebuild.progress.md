## Deviations from spec (with reason)

- M1: kept the Meeting At 10 rows in `docs/voice-and-tone.md` (voice) and `docs/logo-and-assets.md` (text wordmark, do not use the ACCS mark). They guide the team site's content and identity, which decision 8 keeps ("sets itself apart through content and layout"); only the color theme was dropped. README surface row now says the team site uses `accs-landing`.
- M1: started an `[Unreleased]` CHANGELOG section now so M9 only finalizes it.
- M2: `font` is inherited as a computed value, so density text is re-applied on `.ds-body [data-density]` (otherwise a compact subtree kept 16px). Spec did not mention this.
- M2: `.theme-*` classes dropped along with the old names (data-theme works on any element, so they were redundant).
- M2: the new theme docs leave out lines that later decisions overturn: "teal and purple only as chips" (tiles, decision 4), landing radius "cards 8" (decision 13), "three ds-cards" pillars (card rule, decision 15).
- M5: TypeScript pinned to 5.9.3 although 7.x is current: M7 generates props tables with the TypeScript compiler API, which the native 7.x build does not expose the same way; the apps also use 5.x.
- M5: versions pinned exactly: react-aria-components 1.22.1 (dependency); react/react-dom 19.3.1, vitest 5.0.5, jsdom 30.1.3, @testing-library/react 16.3.3, @testing-library/dom 10.4.2, @testing-library/user-event 14.6.8, axe-core 4.14.0, @types/react(-dom) 19.3.0 (dev).
- M5: `tsconfig.json` (noEmit, includes tests, used by `typecheck` and Vitest) + `tsconfig.react.json` (emit, excludes tests). `build:react` wipes `dist/react` first so deleted components do not linger.
- M5: test setup registers Testing Library `cleanup` (no Vitest globals). `src/react/test/a11y.test.tsx` proves the axe helper reports a real violation (unnamed button).
- M5: `.ds-btn` blocks pointer events on `[data-pending]` (React Aria pending) as well as `[aria-busy="true"]`.
- M4b: Select listbox uses `radius-tile` (8), not 12: with its 4px padding, 12 would mismatch the 6px option corners; treated like other small floating surfaces (toast).
- M4b: `.ds-table-wrap` keeps its own soft container (card-bg, card-shadow, radius 12): decision 15 forbids wrapping a table in a Card, not giving the table a surface.
- M4b: added CSS for Tile, Wash, Feature Row and Divider now (Phase 1 components) because the templates need them for the look; their specs and React components come in M6.
- M4b: templates changed to follow the card rule: landing pillars -> open feature row with tiles; admin guideline and consultation panels -> open sections; report detail -> headed sections with dividers (0 cards); sign-in panel -> floating `ds-card--overlay` on a wash.
- M4a: added a third layer `ds.utilities` (spec said two) for `.ds-only-mobile/-desktop`; they came after components in the old file and must keep beating component `display` values.
- M4a: text field, text area and select trigger share one `control/field.css` (they share selectors); listbox/option in `control/select.css`. Spinner in `feedback/spinner.css`, skeleton stays with view state, app shell in `navigation/app-shell.css`.
- M4a: nesting only for contiguous rules of the same single selector, so source order and specificity never change; selector lists stay flat.
- M4a: tokenized only where the value matches a token or the spec named it: spinner -> `size-icon-16`, checkbox box -> `size-icon-20`, eyebrow/tag-mono -> new `size-eyebrow` (11px) / `size-eyebrow-line` (16px) (NOT IN FIGMA). Remaining literals (badge 5/10/6px, 28px sidebar gap, 128px tab, 560px modal, day 3rem, slot 5rem, timeline dot geometry) are one-off component measurements; tokens would add names without reuse.
- M4a: `--ds-ring` is declared on `:where(*)` so `--ring-gap` and the theme surface resolve on the element that draws the ring.
- M3: one file `tokens/treatments.json` (light/dark/all per token) instead of `tokens/treatments/{light,dark,shared}.json`: light and dark sit side by side, one loader.
- M3: `card-highlight(-hover)` folded into `card-shadow(-hover)` for dark (a single box-shadow variable per card state). Added `scrim` treatment so `.ds-scrim` no longer uses a primitive (`--ds-brand-source-ink`).
- M3: `lift` is a px literal (`-2px`); check:tokens allows px only as geometry, never colors.
- M3: `color-mix()` is banned in `src/` and `site/` entirely; blends live only in treatments.
- M2: contrast output still labels themes by file name (`accs-light`, `accs-dark`); file names stay because `import:figma` writes them.
