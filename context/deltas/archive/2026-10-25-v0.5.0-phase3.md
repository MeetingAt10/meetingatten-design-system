## Rules

- Copy from the Figma frames; synthetic content is labeled `DEMO`; no promises of anonymity, security, response time or finality.
- Slots use one radio group (Figma 05); booked and unavailable slots are disabled and say so in text.
- Reports: status in words; permission and identity visibility stay separate statements (Privacy Notice); never sensitive preview text in tables or records.
- On mobile, show Report Records instead of the Reports Table (`ds-only-mobile` / `ds-only-desktop`).

## Follow-up: layer order, page weight, OG names (2026-10-25)

- Bug: in the site (and any Tailwind app following the README), the compiled layer order was `properties, theme, base, components, utilities, ds.*`, so `ds` rules beat Tailwind utilities (`ds-card p-4 rounded-tile` computed 24px padding / 12px radius). Fix: `@layer properties, theme, base, ds, components, utilities;` before `@import "tailwindcss"`; same element now computes 16px / 8px. README updated.
