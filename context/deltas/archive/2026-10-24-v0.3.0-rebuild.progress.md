They guide the team site's content and identity, which decision 8 keeps ("sets itself apart through content and layout"); only the color theme was dropped. README surface row now says the team site uses `accs-landing`.
- M1: started an `[Unreleased]` CHANGELOG section now so M9 only finalizes it.
- M2: `font` is inherited as a computed value, so density text is re-applied on `.ds-body [data-density]` (otherwise a compact subtree kept 16px). Spec did not mention this.
- M2: `.theme-*` classes dropped along with the old names (data-theme works on any element, so they were redundant).
- M2: the new theme docs leave out lines that later decisions overturn: "emerald and purple only as chips" (tiles, decision 4), landing radius "cards 8" (decision 13), "three ds-cards" pillars (card rule, decision 15).
- M9: README intro, layout, install pin (`#v0.3.0`) and rules; CONTRIBUTING split into "Figma first" (color, type, dimensions) and "repo first" (look, components) with the card rule and the Figma push step; principle 1 rewritten ("Soft layers on a real structure"); CHANGELOG `[0.3.0] - 2026-10-24`; package 0.3.0; delta, progress and prompt moved to `context/deltas/archive/`.
- M8: deploy reads bucket, distribution, site URL and role ARN from repository variables (`DESIGN_SITE_*`) instead of CloudFormation outputs, so the deploy role needs no `cloudformation:DescribeStacks`; the job is skipped while `DESIGN_SITE_ROLE_ARN` is unset.
- M8: OG images (extensionless) are excluded from `s3 sync` and uploaded with `--content-type image/png`.
- M8: actions pinned by major tag (checkout@v4, setup-node@v4, configure-aws-credentials@v4); pin to commit SHAs if the org requires it.
- M8: CI triggers on pushes to `master` and `main` (local default branch is `master`; GitHub default unknown).
- M7: demos and props tables are added to a page by its frontmatter (`react`, `demo`) instead of inline `<Demo>` tags in the markdown: the specs stay plain markdown that GitHub renders, and MDX parsing of the existing docs is avoided (rendered as CommonMark + GFM).
- M7: canonical/OG origin comes from `NEXT_PUBLIC_SITE_URL` (same variable the apps use) instead of `SITE_URL`; default `http://localhost:3000`, so the deploy build must set it.
- M7: the site installs the package as a packed copy (`site/.npmrc install-links=true`) so React resolves once; `npm --prefix site run refresh` re-packs after package changes (plain `npm install` does not).
- M7: Open Graph images are emitted as extensionless files (`.../opengraph-image`); the deploy step must upload them with `Content-Type: image/png` (M8).
- M7: props tables merge this package's own base interfaces (for example Field's `label`, `description`, `errorMessage`) and name the React Aria bases.
- M7: color swatches and the type scale (`demo: Swatches` / `demo: TypeScale` on foundations/color.md and typography.md) replace the preview catalog's token tables; rendered at build time from dist/tokens.json.
