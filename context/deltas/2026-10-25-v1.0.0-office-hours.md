# Delta: v1.0.0 "Office Hours" redesign

Status: in progress (branch `redesign/v1`). Decided 2026-10-25 with the user: Figma is no longer a reference; every component and style may be rewritten; add icon and motion libraries; keep the ACCS palette (54 primitives + light/dark mapping) and fonts (Plus Jakarta Sans, Inter, JetBrains Mono); all three surfaces (ACCS landing, ACCS portal/admin, Meeting At 10) weigh equally; must not feel playful, generic SaaS, cold/bureaucratic, or slowed by motion. Product truth: `PRODUCT.md`. Direction contract: `.impeccable/surfaces/site-app-examples-landing-page-tsx.md` (seed 94a7f4c0, "Office Hours", code-led).

## 1. The world

The weekly consultation timetable taped to a CCS faculty door, rebuilt as an interface language.

| Element | Expression |
|---|---|
| Sheet | Paper-white surface on a cool canvas; a 1px rule border, no shadow at rest (flat paper) |
| Rules | 1px hairlines (`border-subtle`); where a grid is drawn it is a real, labeled time grid (hours, days), never decoration |
| Block | The unit of content: a rectangle (radius 6) whose lane color owns the whole fill at full strength; time code top line in tabular JetBrains Mono, title in Inter 600, meta below |
| Lanes | community = accent (violet), consultations/support = secondary (teal), schedule/brand = action (navy), restricted reports = neutral ink + hatch (no hue: color never signals confidentiality) |
| Highlighter | Flat 100/950-step washes behind text for selection, search hits and emphasis; swiped in from the left |
| Hatch | Diagonal hairlines on taken, restricted or unavailable areas, always with a word |
| Door plate | Navy plate (light) / pale-blue plate (dark) with Plus Jakarta Sans 800 text and an optional mono room code: brand lockup, app page titles |
| Now-line | 2px line + dot in `now` (danger 700 / 300), labeled with the time; the system's "current" marker in time contexts |
| Line-form states | solid = open/active, dashed = pending/draft, hatched = taken/restricted, struck = disabled/closed; always paired with a word or icon |
| Current item | Becomes a solid block (navy fill, fill-weight icon); hover is a highlighter wash |

Refusals (craft floor): no kickers/eyebrows above headings, no colored border-left/right stripes over 1px, no same-size icon-card columns as page structure, no hero-metric template, no gradient text, no decorative glass, no mono as costume (mono only for times, codes, references, keys, code), no ghost cards (border OR shadow, never both), no emoji.

## 2. Tokens (repo-owned; `tokens/` is the source)

- Figma removed: `figma/`, `scripts/import-figma.mjs`, `scripts/parity.mjs`, `tokens/figma-known-failures.json`, `docs/figma-parity.md`, `assets/icons/figma/`.
- Color primitives and the light/dark mapping unchanged. Theme additions only: `now`, `hatch-ink`, `inverse-bg`, `inverse-fg`, `plate`, `on-plate`.
- Type (same families; new scale): display 800 fluid 44-80px / 1.02 / -0.035em; h1 700 fluid 32-44 / 1.1 / -0.03em; h2 700 fluid 24-30 / 1.2 / -0.025em; h3 700 20 / 1.3 / -0.015em; h4 600 17 / 1.4; body-large 18/29; body 16/26; body-small 14/22; label 600 14/20; caption 500 12/16; code mono 13/20; time mono 500 12/16 tabular. Families gain the fontsource variable names first (`"Inter Variable"`, ...).
- Density: comfortable text = body, sections 64/96; compact text = body-small, sections 24/32.
- Space adds 2, 12, 20, 128. Radius: 2, 4, 6, 8, 12, 16, full. Size: control 40/48/56 (coarse pointers min 44), icon 16/20/24/32, sidebar 16rem, top bar 64px, focus ring 2px + 2px gap, hour row 48 (compact 40).
- Elevation: ink-tinted, offset + soft blur only: `shadow.lift` (hovered/dragged block), `shadow.overlay` (menus, popovers, dialogs, toasts). Dark: deeper black shadows + 1px top highlight.
- Motion: durations instant 0 / quick 120 / base 200 / slow 320 / deliberate 480; eases out-expo `(0.16,1,0.3,1)`, in-out, exit, standard; springs snappy (600/40), smooth (420/40), gentle (260/32) emitted as CSS `linear()` curves with settle durations (scripts/lib.mjs `springCurve`) and as Motion configs (`src/react/lib/motion.ts`, generated); distances lift 2, drop 6, rise 8.
- Treatments: sheet, block, overlay, plate, highlight-{community,consult,schedule,neutral}, hatch (new grammar `{ "hatch": ref, "alpha": n }`), scrim, radius mapping, motion distances. `check:tokens` validates the grammar and still forbids raw colors in `src/` and `site/` (system colors only in forced-colors.css).

## 3. Libraries

| Library | Version | Use |
|---|---|---|
| `@phosphor-icons/react` | 2.1.10 | All icons. Weights carry meaning: regular (UI), fill (selected/current), duotone (lane/category icons, the 20% layer reads as highlighter). Re-exported at `@meetingat10/design-system/icons`; `Icon` adapter keeps a curated `name` API |
| `@phosphor-icons/core` (dev) | 2.1.1 | Builds `assets/icons/sprite.svg` for the plain-CSS layer from the curated list (`assets/icons/icons.json`) |
| `motion` | 14.6.0 | `m` components under `LazyMotion` (domMax) from `DesignSystemProvider`: toast stack + swipe, drawer drag, disclosure height, tab panel crossfade, timetable block layout, landing orchestration. Without the provider, components render static |
| `@number-flow/react` | 0.6.2 | Animated digits: now-line clock, progress and meter values, counts |
| `@fontsource-variable/{inter,plus-jakarta-sans,jetbrains-mono}` | 5.3.0 | `dist/fonts.css` (optional) self-hosts the pinned families for non-Next apps |
| `react-aria-components` | 1.22.1 | Behavior and a11y; `SelectionIndicator` for tab/segment/day indicators (CSS-animated) |

CSS-layer motion stays native: `@starting-style`, `[data-entering]/[data-exiting]` keyframes, `linear()` springs, `prefers-reduced-motion` turns transforms off and shortens fades to instant.
